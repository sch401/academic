# Chao Song — Academic website

Personal academic website built with the original [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

Website: https://sch401.github.io/academic/

## Updating the site

* Profile and contact details: `_config.yml`
* Navigation: `_data/navigation.yml`
* About, research, CV, talks and teaching: `_pages/`
* Publication records: `_publications/`
* Profile photograph: `images/chao-song.jpg`

Commits pushed to `master` are built and published by `.github/workflows/jekyll.yml`.

The template retains its original MIT license in `LICENSE`.
